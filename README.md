# WorkNest

**WorkNest** is a full-stack workspace management platform designed to help teams organize tasks, manage workspaces, and collaborate efficiently. The platform provides a modern web interface along with a scalable backend API for managing projects and workflows.

---

## Features

* Workspace creation and management
* Task organization and tracking
* Team collaboration support
* Modern responsive UI
* Backend API for scalable integration

---

## Tech Stack

### Frontend

* React
* Vite
* TypeScript
* Tailwind CSS

### Backend

* Django

## Installation & Setup

### 1. Clone the Repository

```
git clone https://github.com/sripadsanand/Worknest-Updates.git
```

### 2. Navigate to the Project Folder

```
cd Worknest-Updates
```

---

# Frontend Setup

Navigate to the frontend directory:

```
cd frontend
```

Install dependencies:

```
npm install
```

Run the development server:

```
npm run dev
```

The frontend will run at:

```
http://localhost:5173
```

---

# Backend Setup

Navigate to the backend directory:

```
cd backend
```

Create a virtual environment:

```
python -m venv venv
```

Activate the environment

Windows:

```
venv\Scripts\activate
```

Install backend dependencies:

```
pip install -r requirements.txt
```

Run the Django server:

```
python manage.py runserver
```

Backend will run at:

```
http://127.0.0.1:8000
```
